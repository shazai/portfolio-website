# Personal Portfolio

A responsive personal portfolio built with **HTML, custom CSS, Bootstrap 5.3.3, and mobile-first media queries**.

## Live Demo

Add your GitHub Pages URL here after deployment:

`https://shazai.github.io/portfolio-website/`

## Features

- Responsive Bootstrap navbar with a collapsible mobile menu
- Hero section with a profile-image placeholder
- About, Skills, Projects, and Contact sections
- Bootstrap containers, rows, columns, cards, buttons, badges, and forms
- Mobile-first custom media queries at 576px, 768px, 992px, and 1200px
- Project cards that display 1 per row on mobile, 2 on medium screens, and 3 on large screens
- Flexible images and accessible labels/alt text
- GitHub Pages-ready static file structure

## Technologies

- HTML5
- CSS3
- Bootstrap 5.3.3
- Git
- GitHub / GitHub Pages

## Local Viewing

Open `index.html` in a browser. Because Bootstrap is loaded through a CDN, an internet connection is needed for Bootstrap styling and the collapsible navbar JavaScript.

## Note About the Contact Form

The form is currently a front-end demo. It does not send messages until it is connected to a backend or form service.
